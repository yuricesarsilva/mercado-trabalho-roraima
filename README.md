# Mercado de Trabalho em Roraima

Repositório para os artigos sobre mercado de trabalho em Roraima.

## Paper 1

`paper_1_formalidade_genero_raca_rr/`

Tema: diferenciais de rendimento por formalidade, gênero e raça/cor no mercado de trabalho de Roraima, controlando por atividade econômica, ocupação e características individuais nos microdados da PNAD Contínua.

## Organização

Os microdados brutos, intermediários e processados não entram no Git. Os scripts em `paper_1_formalidade_genero_raca_rr/scripts/` documentam como reconstruir a base e gerar os resultados.
